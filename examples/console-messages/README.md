# Console messages

Prints `Spark 1` to `Spark 5`, one second apart, on any Spark board. No wiring and no pins.

Use it to check that a board runs Spark Plugs and that its console reaches BenchVista.

| Setting               | Default | Range          |
| --------------------- | ------- | -------------- |
| Messages              | 5       | 1 to 20        |
| Time between messages | 1000 ms | 100 to 2000 ms |
